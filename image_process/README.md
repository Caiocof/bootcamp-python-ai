# ImageProcess

**ImageProcess** é um pacote Python leve e fácil de usar para processamento de imagens. Ele oferece uma variedade de
funcionalidades para manipulação de imagens, como:
- **Processing:**
  - Histogram matching
  - Structural similarity
  - Resize image
- **Utils:**
  - Read image
  - Save image
  - Plot image
  - Plot result
  - Plot histogram

## Funcionalidades

- **Redimensionamento de Imagens**: Altere o tamanho de suas imagens mantendo a proporção ou definindo dimensões
  específicas.
- **Rotação de Imagens**: Gire imagens em qualquer ângulo, com suporte para rotação automática com base em metadados
  EXIF.
- **Aplicação de Filtros**: Aplique uma variedade de filtros, como desfoque, nitidez, sepia, e mais.
- **Conversão de Formatos**: Converta imagens entre diferentes formatos, incluindo JPEG, PNG, BMP, e TIFF.
- **Corte e Recorte**: Corte suas imagens em áreas específicas ou recorte de acordo com as proporções desejadas.
- **Adição de Texto e Marcas d'Água**: Adicione texto ou marcas d'água às suas imagens com suporte para personalização
  de fonte, cor, e transparência.
- **Suporte a Múltiplos Formatos**: Carregue e salve imagens em vários formatos populares.

## Instalação

Você pode instalar o **ImageProcessor** diretamente do PyPI usando `pip`:

```bash
pip install image_process
```
